Detailed Description

Command that processes Play, Stop, and Skip logic.

This command is triggered by physical button events. It determines the appropriate action (e.g., if playing, stop; if stopped, play) and communicates with the PlayerService to execute the change. It also handles station skipping by interacting with the StationRepository.
