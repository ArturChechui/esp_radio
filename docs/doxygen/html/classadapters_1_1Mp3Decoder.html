Detailed Description

Concrete MP3 decoder implementation using the minimp3 library.

This class manages the internal state of a minimp3 decoder instance. It is used to convert compressed MP3 data chunks into raw 16-bit PCM samples suitable for playback via I2S or other audio interfaces.
