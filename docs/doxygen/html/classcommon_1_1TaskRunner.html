Detailed Description

A task manager providing lifecycle control and static allocation.

Forward declaration of the StopToken class.

The TaskRunner allows the application to start and stop background tasks while maintaining a registry of active tasks. It uses a "slot" system to reuse memory and provides synchronization mechanisms to ensure tasks have fully exited before their resources are reused.
