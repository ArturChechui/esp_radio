Detailed Description

Abstract interface for monitoring task cancellation.

Objects implementing this interface are typically passed to worker loops (e.g., in EventTask or AudioPlayer) to ensure they can be stopped gracefully by the system manager.

virtual bool common::IStopToken::sleepMs ( const uint32_t ms)
pure virtual

Performs a delay that exits early if a stop is requested.

  • This is more efficient than a standard sleep because it allows the task to respond to shutdown signals immediately rather than waiting for the full timer to expire.
  • Parameters
    msThe maximum duration to sleep in milliseconds.
    Returns
    true if the full sleep duration elapsed, false if interrupted by a stop request.
