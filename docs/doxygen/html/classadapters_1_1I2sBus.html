Detailed Description

Concrete implementation of an I2S bus controller for audio transmission.

  • This class provides a high-level wrapper around the ESP-IDF I2S driver, specifically configured for standard (STD) mode transmission. It allows for dynamic sample rate reconfiguration and synchronous data writing.
