Detailed Description

Concrete implementation of a Wi-Fi provisioning portal using ESP-IDF's HTTP server.

This class hosts a simple web application that allows users to connect to the device's Access Point and submit their local Wi-Fi SSID and password via a web form. It handles URL decoding of form data and dispatches credentials via a callback.
