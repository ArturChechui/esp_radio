◆ toTicks()

TickType_t common::toTicks ( const uint32_t  ms)
inline

Converts a millisecond duration to FreeRTOS ticks.

  • This function calculates the equivalent number of system ticks for a given time in milliseconds. It performs a "ceiling" division to ensure that the resulting delay is at least as long as requested.
  • Parameters
    msThe duration in milliseconds to convert.
    Returns
    The equivalent number of TickType_t ticks.
  • Returns portMAX_DELAY if the input is UINT32_MAX.
  • Returns 0 if the input is 0.
  • Returns the calculated ticks (rounded up) otherwise.
