Detailed Description

Concrete implementation of the audio player engine.

PlayerService implements a producer-consumer architecture for audio playback. An HTTP task (the producer) fetches MP3 data and writes it to a ring buffer, while a playback task (the consumer) reads from the buffer, decodes the MP3 frames, and writes the resulting PCM samples to the I2S bus.
