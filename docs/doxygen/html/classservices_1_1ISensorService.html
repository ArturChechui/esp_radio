Detailed Description

Abstract interface for a sensor coordination service.

This service provides a standardized way to interact with various sensors (e.g., light sensors, temperature sensors) and control the activation state of audio input hardware like microphones.

When disabled, all calls to startClapDetection(true) are ignored. This state is saved to persistent storage.
