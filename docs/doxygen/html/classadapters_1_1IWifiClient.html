Detailed Description

Abstract interface for a Wi-Fi hardware controller.

This interface encapsulates the complexity of the Wi-Fi stack (like ESP-IDF Wi-Fi). It supports standard station mode (connecting to a router) and Access Point (AP) mode (hosting a network), along with asynchronous state callbacks.
