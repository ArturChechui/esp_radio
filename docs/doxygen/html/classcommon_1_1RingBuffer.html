Detailed Description

A thread-safe circular buffer implementation optimized for audio pipelines.

This implementation is designed for the "audio pipeline" use case:

  • 1 producer task (e.g., HTTP reader)
  • 1 consumer task (e.g., decoder/player)

It provides thread safety via an internal mutex and offers zero-copy spans * to allow producers and consumers to access the internal memory directly, avoiding extra temporary buffers.
