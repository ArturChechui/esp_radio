Detailed Description

Abstract interface for a circular (ring) buffer.

This interface provides dual access patterns:

  1. Standard Read/Write: Data is copied between user buffers and internal storage.
  2. Zero-Copy Spans: Provides direct pointers to internal memory segments, avoiding unnecessary copies.
