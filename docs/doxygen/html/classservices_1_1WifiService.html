Detailed Description

Concrete implementation of Wi-Fi management logic.

WifiService handles the lifecycle of Wi-Fi connectivity. It attempts to connect using stored credentials, monitors the signal quality via a background task, and launches the provisioning portal if a connection cannot be established.
