Detailed Description

Concrete implementation of a GPIO input controller.

  • This class manages GPIO pins configured as inputs. It supports interrupt-driven event handling by pushing GPIO numbers to a shared queue when state changes occur. It follows a singleton-like pattern for ISR access via a static instance pointer.
