Detailed Description

Abstract interface for a high-level Wi-Fi management service.

This service provides a simplified API for the application to interact with Wi-Fi hardware. It handles the logic for connecting to networks, checking connection status, and triggering the web-based provisioning portal when credentials are missing or incorrect.
