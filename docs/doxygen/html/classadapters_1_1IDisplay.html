Detailed Description

Abstract interface for controlling a display device.

This interface defines the basic operations required to drive a display, including initialization and various methods to push pixel data to the screen.

Performs a windowed write using specific column and page addressing.

  • This method allows updating only a specific portion of the display. The data layout follows: for each page in [page0..page1], and for each column in [col0..col1], push the corresponding byte.
  • Parameters
    col0Starting column address.
    col1Ending column address.
    page0Starting page (row group) address.
    page1Ending page (row group) address.
    dataPointer to the pixel data for the window.
    lenThe size of the window data in bytes.
    Returns
    true if the window update succeeded, false otherwise.
